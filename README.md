# ⚔️ Batalha de Personagens - Desafio Técnico

Este projeto foi desenvolvido como parte do **Desafio Técnico do 1º trimestre** da disciplina de **Linguagens de Programação**. O objetivo é aplicar conceitos de lógica de programação, estruturas de repetição, funções e manipulação de variáveis em um sistema simples de batalha entre personagens.

---

## 📌 Descrição

O programa simula uma batalha entre dois personagens com atributos pré-definidos, como força, agilidade, inteligência, vida, origem e experiência.

Durante a execução, o sistema:

- Exibe as informações dos personagens
- Calcula a força ofensiva de cada um
- Compara os valores
- Determina o vencedor ou empate
- Permite repetir a batalha quantas vezes o usuário quiser

---

## ⚔️ Método de Batalha

O método utilizado é o de **OFENSIVA**, calculado da seguinte forma:

**Ofensiva = Força + Agilidade**

O personagem com maior valor de ofensiva é declarado vencedor.
